# Rally Horizon 3D 🏎️💨

Ультра-лёгкая 3D-игра в стиле **Rally Horizon** на чистом HTML, CSS и Three.js (подключен через CDN, без тяжелых сборщиков и внешнего бэкенда). 

Работает прямо в браузере с 60 FPS на ПК, планшетах и мобильных устройствах.

## 🌟 Особенности игры

- **5 уникальных автомобилей**:
  - `Apex Horizon GT` — Аэродинамичный гиперкар со скошенным носом и GT-антикрылом.
  - `Rally Beast 4x4` — Турбированный раллийный хэтчбек WRC с длинноходной подвеской.
  - `Nightdrift S15` — Легендарное японское дрифт-купе с выворотом колес 65°.
  - `Thunder V8 RT` — Американский маслкар с мощным двигателем V8 Hemi.
  - `Dakar Raptor 4x4` — Внедорожный трофи-трак с гигантскими 37-дюймовыми шинами.
- **Огромная открытая 3D-карта**:
  - Скоростное кольцо с текстурированным асфальтом, разметкой и красно-белыми гоночными поребриками.
  - Извилистый гравийный раллийный спецучасток с колеями и пылью.
  - 4 больших трамплина с физикой затяжных прыжков.
  - Фестивальная арка старта/финиша со световыми мачтами и стадионными прожекторами.
- **4 игровых режима**:
  - `Свободная езда (Free Roam)` — исследование мира, счётчик дальности прыжков и дрифт-комбо.
  - `Horizon Grand Prix` — кольцевая гонка на 2 круга по контрольным точкам.
  - `Rally Mountain Sprint` — гравийный спринт по горной тропе от точки к точке.
  - `Gymkhana Drift (60 сек)` — челлендж на максимальный набор очков дрифта за минуту.
- **Реалистичное сенсорное управление (для планшетов и телефонов)**:
  - Большой интерактивный виртуальный руль (240px) с физикой вращения.
  - Спортивные педали газа (185px) и тормоза (130px) с 3D-анимацией нажатия.
  - Кнопки закиси азота (баллон NOS) и дрифта (силуэт спорткара).
  - Спидометр по центру и радар в левом верхнем углу.
- **Синтезатор звука на Web Audio API**:
  - Процедурный звук мотора, визг шин в заносе, рёв нитро и звуки чекпоинтов без внешних MP3-файлов.

## 🎮 Управление

| Действие | Клавиатура | Сенсорный экран |
|---|---|---|
| **Руление** | `A` / `D` или `←` / `→` | Вращение виртуального руля |
| **Газ (Акселератор)** | `W` или `↑` | Педаль «ГАЗ» |
| **Тормоз / Задний ход** | `S` или `↓` | Педаль «ТОРМОЗ» |
| **Ручной тормоз / Дрифт** | `Пробел (Space)` | Кнопка «ДРИФТ» |
| **Нитро (Закись азота)** | `Левый / Правый Shift` | Кнопка «НИТРО» (баллон NOS) |
| **Смена вида камеры** | `C` | Кнопка камеры в HUD |
| **Сброс машины на трассу** | `R` | Кнопка сброса в HUD |
| **Гараж / Пауза** | `G` или `Escape` | Кнопка «Гараж» |
| **Вкл/выкл звук** | `M` | — |

## 🚀 Как запустить локально

В терминале перейди в папку с игрой и запусти встроенный сервер:

```bash
python3 -m http.server 8080
```

Затем открой в браузере:
```
http://localhost:8080
```
